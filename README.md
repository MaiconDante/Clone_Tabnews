# 🚀 Projeto Curso.dev — TabNews Clone

Este repositório documenta o desenvolvimento de um projeto prático construído do zero durante o curso **curso.dev**, idealizado por **Felipe Deschamps**.

O objetivo é recriar uma versão simplificada do **TabNews**, aplicando conceitos fundamentais de engenharia de software, boas práticas de desenvolvimento e construção de sistemas reais.

---

## 🧠 Sobre o Projeto

Este projeto está sendo desenvolvido de forma incremental, acompanhando a evolução dos conceitos apresentados no curso.

A proposta não é apenas copiar uma aplicação, mas **entender profundamente como sistemas web funcionam por trás dos bastidores**, construindo cada parte manualmente.

Durante o desenvolvimento, são abordados conceitos como:

* Estruturação de aplicações web do zero
* Boas práticas de organização de código
* Versionamento com Git e GitHub
* Arquitetura de software
* Banco de dados e persistência de dados
* APIs e comunicação entre sistemas
* Deploy e infraestrutura básica

---

## 🏗️ Status do Projeto

📌 Em desenvolvimento (build in progress)

Este projeto está sendo construído gradualmente, acompanhando cada etapa do curso.

Cada nova aula adiciona uma nova camada de entendimento e implementação.

---

## 🛠️ Tecnologias em uso

As tecnologias utilizadas estão sendo introduzidas conforme o avanço do curso:

* Node.js
* JavaScript (backend e lógica de aplicação)
* Git e GitHub
* SQL / Banco de Dados (quando aplicado)
* APIs HTTP
* HTML/CSS (quando necessário para interface básica)

Este repositório tem como objetivo:

* Desenvolver pensamento de engenharia de software
* Aprender boas práticas de código limpo e organização
* Simular um ambiente de desenvolvimento profissional
* Evoluir do básico ao entendimento de sistemas completos
